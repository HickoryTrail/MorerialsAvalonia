# MorerialsAvalonia v1.1.0

## 新增

- 将桌面捕获管线迁移到 DXGI Desktop Duplication，并支持帧元数据、移动矩形和脏矩形更新。
- 增加捕获帧与渲染消费者之间的生命周期同步，避免桌面表面失效后继续访问。
- 增加 GPU 资源、Avalonia 外部图像和控件会话的完整释放路径。
- 增加渲染诊断、着色器预热及相关集成文档和测试覆盖。

## 修复

- 修复演示程序启动后因释放 Desktop Duplication 帧过早而导致的黑帧、GPU 错误和原生崩溃。
- 修复输出槽重建时 Avalonia 导入图像对象泄漏的问题。
- 修复渲染异常、控件卸载和异步初始化竞态导致的后台线程、定时器及 D3D11 资源残留。
- 修复停止捕获时旧线程仍访问已释放 D3D11 设备的问题。
- 修复窗口失焦、停用或控件卸载后 LiquidGlassButton 可能永久保持按下状态的问题。

## 兼容性

- Windows 10 2004 (19041) 或更高版本。
- Avalonia 12.1.0 与 .NET 10。
- 不支持的设备仍不提供 CPU 或静态回退，请由宿主自行处理。
