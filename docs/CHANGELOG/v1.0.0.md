# MorerialsAvalonia v1.0.0

## 首个公开版本

- 提供 `MaterialHost`，为单个 Avalonia 顶级窗口提供所有材质共享的 Windows Graphics Capture 与 D3D11 合成上下文。

- 支持 LiquidGlass 材质，并支持以下控件:`LiquidGlassContainer`、`LiquidGlassButton`



## 兼容性

- Windows 10 2004 (19041) 或更高版本。
- Avalonia 12.1.0 与 .NET 10。
- > [!WARNING]
  > 
  > 本项目不为不支持的设备提供 Fallback，请自行处理不支持的情况。
