# MorerialsAvalonia v1.0.0

## 首个公开版本

- 发布 `MaterialHost`，为单个 Avalonia 顶级窗口提供共享的 Windows Graphics Capture 与 D3D11 合成上下文。
- 发布 `LiquidGlassContainer`、`LiquidGlassButton`、`LiquidGlassMaterial` 和默认材质预设。
- 发布 `MaterialForeground` 附加属性：每个材质内容控件独立进行低频 GPU 亮度采样，并自动选择深色或浅色前景。
- 发布用户侧 `MaterialShaderCompiler.EnsureCompiledAsync`：内置 HLSL 在用户机器编译并缓存；未预热时宿主会自动补编译。
- 发布 `MaterialRenderDiagnostics`，用于观察着色器、WGC、D3D11 和帧率状态。
- 发布 `LiquidGlass.DemoGallery` 的 `win-x64` self-contained、trimmed 发行包。

## 兼容性

- Windows 10 2004 (19041) 或更高版本。
- Avalonia 12.1.0 与 .NET 10。
- 不提供 CPU 截图、CPU 模糊或静态图像回退。
